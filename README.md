# EasyEdit

**Your photos. Your ideas. A little help from AI.**

EasyEdit is an AI-powered photo editing app for Android that brings creative AI tools and everyday photo editing into one place. From removing backgrounds and transforming images with text prompts to applying filters and making quick adjustments, EasyEdit makes photo editing simple and accessible.

### Features

- **AI Image Editing** — Edit photos using natural-language prompts.
- **Background Removal** — Remove backgrounds and create clean cutouts.
- **AI Image Generation** — Explore creative styles and transform your photos.
- **Image Expansion** — Extend images beyond their original boundaries.
- **AI Filters & Effects** — Give photos a fresh, creative look.
- **Essential Editing Tools** — Crop, rotate, adjust brightness and contrast, apply filters, add text, and mark up images.
- **Image History** — Access your saved edits.
- **Token-Based System** — Use tokens to access eligible premium features.

### Built With

- React Native
- Expo
- TypeScript
- NativeWind
- gluestack-ui
- Supabase — Authentication, database, storage, and Edge Functions
- Google Gemini — AI-powered image generation and editing

### Project

This repository contains the **EasyEdit website**, which supports the mobile application with product information, legal policies, contact details, and account-deletion resources.

### Vision

EasyEdit aims to make powerful photo editing approachable for everyone, combining quick everyday adjustments with AI-powered creative possibilities.
